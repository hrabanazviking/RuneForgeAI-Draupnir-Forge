# Goal: hello-forge

Build a tiny CLI that greets by name and remembers the last greeting.

It must be a single Python script with no dependencies beyond the
standard library. The greeting must include the person's name, and the
name of the last person greeted must survive between runs — a small
file in the user's home directory is fine.

This is a learning exercise, so keep it small and readable; do not add
a database, a web server, or a configuration system. It should be
possible to verify by hand: run it twice with different names and check
that it recalls the previous one.

Should the greeting be in English only, or should it support other
languages from the start?
